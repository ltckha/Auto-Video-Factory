# Git Push Policy: Only Push When Explicitly Requested by User

## Core Directive
- **DO NOT** automatically push code to Git or ask/remind the user to push to Git after completing tasks.
- **ONLY** execute `git push` or propose pushing to Git when the user **EXPLICITLY** requests or commands it (e.g. "đẩy lên git đi", "push git").
- Keep local code changes tested, clean, and verified without making unprompted Git pushes.
